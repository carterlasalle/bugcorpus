# bug-learn

<!-- trace:v1 id=doc.bugcorpus-cmd.learn work=WORK-BUG-ZJBDCZZ0 -->

Learn the just-fixed bug ($ARGUMENTS) into Bug Corpus. Read the
`bug-corpus` skill first, then follow it: fix proven by normal tests,
`uv run bugcorpus learn --title "..."`, state symptom vs root cause vs
violated invariant, search for sibling bugs, extend an existing detector
before creating one, verify fixtures, attack the detector, recommend
shadow first.
