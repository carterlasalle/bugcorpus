# bug-corpus

<!-- trace:v1 id=doc.bugcorpus-cmd.status work=WORK-BUG-ZJBDCZZ0 -->

Show the Bug Corpus status: known bugs, families, and detectors.

Run `uv run bugcorpus doctor` and summarize capabilities, then
`uv run bugcorpus scan --profile fast` and report new findings only.
For the full learn-and-synthesize workflow, read the `bug-corpus` skill.
